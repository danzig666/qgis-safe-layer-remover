changelog=1.2.1 Much faster layer removal: the sentinel no longer runs a full analysis for every removal (about 1.9 s -> 0.02 s per removal in a 380 layer project); helper layers never shown in the Layers panel are ignored; faster analysis through per-layer caches.
 1.2.0 Optional undo for every layer removal (also from the Layers panel); undo restores the original layer id, tree position, joins, relations, map themes and layout maps. Recycle bin limits. Mark / unmark several layers for removal from the context menu. "Select all" picks untouched layers only. Wider name column, window can't be minimized.
 1.1.0 Personal layer locks: lock / unlock layers (several at once) so they cannot be removed; padlock icon in the list and in the Layers panel.
 1.0.2 Manually edited legends and layout custom properties no longer mark every layer as being on a layout.
 1.0.1 New "Untouched only" filter: layers whose removal affects nothing.
 Map items that neither lock their layers nor follow a map theme no longer count as "on a layout".
